## Research to prototype stages

1. **PARKED IDEA / UNSTUDIED:** preserve title, source, questions and constraints; no assumption work is requested now.
2. **SCOPED STUDY:** verify current VEFR behavior, identify actual consumer need, compare small alternatives, record links and risks.
3. **PROPOSED REVERSIBLE PROTOTYPE:** small synthetic/sample world fixtures, feature-flagged if applicable, with performance, accessibility and migration tests described.
4. **OWNER DIRECTION:** if the experiment changes gameplay taste, audiovisual identity, security or backwards compatibility, cite the actual decision rather than guessing.
5. **ACTIONABLE IMPLEMENTATION:** only then create a focused GitHub issue / existing mission with an acceptance command, required checks and scoped rollback.
6. **VERIFIED / REJECTED:** actual evidence of gameplay/system outcomes. A merged docs register does not qualify.

## Suggested probes (no work launched)

- **#500 Wave-function-collapse floors:** is there a real need beyond seeded current floor construction? Compare solvability, variety, browser performance and fallback in a synthetic fixture. Never replace accepted Cottage floors by default.
- **#501 Optional Ink dialogues:** prove one small conversation *only if* actual independent authors benefit over the existing dialogue system; avoid a required new runtime.
- **#502 Music in the always-layer:** inspect current audio and reduced-motion/accessibility settings, then show one reversible UI specimen. Game-specific audio/canon stays in its pack.
- **#504 Stakes as a mechanic:** offer alternative player consequences grounded in observable existing gameplay, no punitive default; Rylee chooses meaning if genuinely undecided.
